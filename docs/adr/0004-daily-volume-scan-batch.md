# ADR-0004: 시장 전체 거래량 탑50 = 일배치 스캔 + 저장

> 상태: Accepted · 날짜: 2026-06-22 · 관련: #416 · 확장: ADR-0003

## 맥락
시장 전체 "오늘 거래량 탑50" 요구. 토스 Open API 실측:
- 랭킹/종목목록/지수구성 API **전무**(404 또는 symbols 필수).
- 거래량은 종목별 `candles` 1콜로만 취득.
- 레이트리밋(BASIC) **실측 ~25 버스트 후 429, 지속 ~10콜/s**.

전 종목(KOSPI+KOSDAQ ≈2,605)을 매 요청마다 스캔하는 것은 불가.

## 결정
1. **유니버스 = KRX 전체 상장(corpList)** 시드(`universe-krx.json` → `UNIVERSE` 테이블).
2. **거래량 스캔은 1일1회(+수동) 백그라운드 배치**, 스로틀(~110ms)+429 백오프. 결과 탑50을 `VOLUME_RANK` 에 `as_of` 와 저장.
3. 페이지는 **저장된 결과를 즉시** 표시(폴링으로 진행률/완료 갱신). 스캔은 `@Async`, 스케줄은 `@Scheduled`.
4. 현재가/등락률은 탑50에 한해 `prices`+`candles(count=2)` 로 보강.

## 근거
- 랭킹 API 부재 + 레이트리밋 → 사전 계산(배치)·캐시(테이블) 외 방법 없음.
- 거래량은 일 단위로 의미 → 일배치 적합.

## 결과 / 함의
- 첫 스캔 ~5분(이후 조회 즉시). 단일 인스턴스 가정(ScanStatus 메모리).
- 유니버스에 ETF/우선주/스팩 포함 → 후속 필터 과제.
- 거래대금 기준/장중 갱신은 후속.
