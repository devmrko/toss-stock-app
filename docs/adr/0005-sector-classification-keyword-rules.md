# ADR-0005: 섹터 분류 = 키워드 규칙(업종+제품+이름)

> 상태: Accepted · 날짜: 2026-06-22 · 관련: #418

## 맥락
종목에 테마 태그(반도체/바이오/건설/화장품/엔터…)가 필요. 토스 API엔 섹터 정보 없음. KRX 업종(KSIC)은 있으나 세분·부정확(삼성전자=통신장비, 아모레=화학제품, 하이브=오디오물 출판).

## 결정
- **업종(KSIC) + 주요제품 + 종목명**을 합친 텍스트에 **우선순위 키워드 규칙**을 적용해 단일 버킷으로 분류(`SectorClassifier`).
- 분류 입력(ksic, product)은 `UNIVERSE`에 저장, 결과(sector)는 스캔 시 계산해 `VOLUME_RANK`에 저장.

## 근거
- 업종 단독은 대형주 다수를 오분류 → 제품/이름 보강 필수.
- 외부 테마분류 API 부재/유료 → 규칙 기반이 현실적이며 조정·테스트 용이.

## 결과 / 함의
- 근사 분류(오분류 가능). 키워드/우선순위는 상수로 두어 조정 가능.
- 다중 테마·정밀 테마지수는 후속 과제.
