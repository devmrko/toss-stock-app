# ADR-0003: 거래량 모니터링 유니버스 = 워치리스트 (시장 전체 랭킹 보류)

> 상태: Accepted · 날짜: 2026-06-22 · 관련: #414

## 맥락
"거래량 기준 탑50 모니터링" 요구. 그러나 토스 Open API(BASIC) 실측 결과:
- **랭킹 엔드포인트 없음**: `/rankings`, `/market/ranking`, `/stocks/rankings` 모두 404.
- **전 종목 리스트 API 없음**: `symbols` 를 입력으로 받는 구조(서버가 전체를 주지 않음).
- 거래량은 `candles?symbol=...&interval=1d`(종목당 1콜) 또는 `trades` 로만 취득.

즉 시장 전체(≈2,800종목)를 매 주기 스캔해 탑50을 뽑는 것은 레이트리밋상 비현실적.

## 결정
1. **모니터링 유니버스 = 사용자 워치리스트(`watchlist` 테이블)**. "탑50"은 **워치리스트 내 거래량 정렬+상위 50**으로 해석.
2. 거래량/전일종가는 일봉 candles 로 취득하되 **TTL 60s 캐시**로 콜 절감.
3. 시세는 `prices` 다건 1콜 폴링(5s).
4. **시장 전체 랭킹(B안)** 은 별도 이슈로 분리: 고정 유니버스(예: KOSPI200) 시드 + 장마감 일배치 + 결과 테이블.

## 근거
- watchlist.html 의 본래 의미(내가 고른 종목)와 일치, 오늘 만든 뼈대 재사용.
- 콜 수 상한이 예측 가능(N≤50, prices 1콜 + candles N콜/분).

## 결과 / 함의
- "탑50"의 의미가 *시장 전체*가 아니라 *워치리스트 내*임을 UI/문서에 명시.
- B안 착수 시: 유니버스 시드 출처(거래소 마스터/수기 목록)와 스케줄러(예: Spring `@Scheduled`) 필요.
