# ADR-0006: 2계층 시장 데이터 수집기 (전체 일봉 저장 / 분봉 비저장)

> 상태: Accepted · 날짜: 2026-06-22 · 관련: #419 · 확장: ADR-0004, 대체일부: #416

## 맥락
시장 데이터를 모아 랭킹·차트의 원천으로 삼고자 함. 토스 캔들 실측 제약: `interval`∈{1m,1d}, `count`≤200, 페이지네이션 `before=<ISO>`. 레이트리밋 ~10콜/s.

## 결정
- **계층1(전체 일봉)**: 2,605종목의 일봉 OHLCV **1년치**를 `DAILY_OHLCV`에 저장. 백필(2콜/종목) + 매일 마감 후 갱신(1콜/종목, MERGE upsert).
- **계층2(분봉)**: **저장하지 않음**. 시간봉은 토스 미지원 → 필요 시 1분봉을 라이브 조회/집계(후속).
- **탑50 출처 전환**: 거래량 탑50을 `DAILY_OHLCV` 최신일 쿼리로 산출(기존 #416 live 전종목 스캔 제거). 섹터는 `UNIVERSE.sector`(분류 사전계산) 조인.

## 근거
- 일봉은 하루 1회면 충분 → 저장이 합리적. 분봉은 양 많고 시간봉 미지원 → 라이브가 효율적.
- 탑50을 저장된 일봉에서 쿼리하면 페이지 조회 시 외부호출 0(레이트리밋 무관).

## 결과 / 함의
- 백필 ~26분(1회), 일일갱신 ~13분. 저장 ~65만행(1년).
- `VOLUME_RANK` 사전저장 방식은 불필요해짐(쿼리로 대체).
- 섹터는 `UNIVERSE`에 사전 분류 저장(조회 시 분류 비용 0).
