# 설계서: 행 클릭 → 관련 뉴스 모달 (#427)

> **상태**: Approved · **작성**: [AI] Architect · 2026-06-23
> **추적성** — Redmine: #427 · 기반: #425(뉴스), #426(뱃지) · 구현: `static/top50.html`, `static/watchlist.html`
> · 테스트: 프론트(수동/verify)

## 1. 목적
탑50/워치리스트에서 **행을 클릭**하면 그 종목과 섹터의 **활성 뉴스(호재🟢/악재🔴)** 를 모달로 보여준다. 뱃지(#426)가 "왜 떴는지"를 즉시 확인.

## 2. 범위
- **포함**: 행 클릭 → 모달, 종목+섹터 뉴스 머지 표시(S뱃지·제목·링크·출처·시각·분석). 폴링 무관(모달은 테이블 밖).
- **제외**: 백엔드 변경(기존 `/api/news?key=` 재사용), 무한스크롤/페이지네이션.

## 3. 인수조건
- [ ] 행 클릭 시 모달 오픈, 헤더에 종목명·코드·섹터.
- [ ] `/api/news?key=<코드>` + (섹터 있으면)`/api/news?key=<섹터>` 머지·dedup(id)·published desc.
- [ ] 각 뉴스: S뱃지(키별), 제목(링크), 출처·시각, 분석(rationale). 호재/악재 색.
- [ ] 관련 뉴스 없으면 "관련 뉴스 없음".
- [ ] 워치리스트 삭제(✕) 버튼 클릭은 모달 안 뜸(이벤트 분리).
- [ ] 배경/✕ 클릭으로 닫힘. 폴링이 모달을 닫지 않음.

## 4. 설계
- 행에 `data-symbol/-sector/-name` 부여, `#rows` 위임 클릭. 삭제버튼은 `closest('button')` 가드.
- 모달 DOM은 테이블 밖(폴링 재렌더 영향 없음).
- 섹터 키는 `encodeURIComponent`(한글).
- 뉴스 카드 렌더는 news.html 의 뱃지/색 규칙 재사용.

## 5. 엣지케이스
- 섹터 null → 종목만 조회.
- 동일 뉴스가 종목·섹터 양쪽 → id dedup.
- 조회 실패 → 모달에 "불러오기 실패".
