# 투자 일일 노트 — <YYYY-MM-DD>

> 원칙 소스: [`docs/reference/investment-principles.md`](../reference/investment-principles.md) §3(체크리스트) · §4(매매 룰) · §9(매수 전 체크리스트) · **§13(확증편향 방지 절차 — 항상 적용)**

> ⚠️ **§13 확증편향 체크(작성 전 필수)**: 아래 모든 결론에는 반대 논거를 동일한 노력으로 찾아 채운다. 근거만 쓰고 반대 논거를 비워두지 말 것 — 못 찾았으면 "반증 탐색함, 약함"이라고 명시.

## 보유 종목 점검 (Holdings Check)

> 데이터 소스: `http://localhost:8081/api/holdings` (`netQty > 0`인 활성 보유만). 지수 비교는 KODEX 200(069500)의 동일 기간 등락률 사용.

| 종목(티커) | 평단→현재가 | 1일/7일 등락 | 미실현손익 | 하드손절가(진입 설정) | 하드손절 여부 | 고점→현재(고점대비) | 추적손절 판정 (§4) | 지수 대비 7일 | 액션 신호 | 반대 논거(Bear) | 확실성 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | 확인됨/확인필요/반증있음 |

**판정 기준**
- **하드손절**: 진입가 대비 포지션별 `stopPct`(API 값, 통상 -8~10%) 이탈 시 발동 — API `belowStop=true`
- **추적손절(§4)**: 미실현손익이 대략 +100% 이상(멀티배거)이면 완화밴드 **-15~20%**, 아니면 표준 **-10%** 적용. 고점 대비 하락폭(`ddFromPeak`)이 이 밴드를 넘으면 "이탈"로 표기
- **지수 대비**: 종목 7일 등락 − KODEX 200 7일 등락 (양수면 아웃퍼폼)
- **액션 신호**: 🔴 밴드 이탈(원칙상 매도선 통과) · 🟠 밴드 상단 근접(임박) · 🟡 경계선/관찰 · 🟢 이상 없음
- **반대 논거(Bear)** (§13 필수): 액션 신호를 뒤집을 만한 근거 — 예: 실적 발표 임박, 섹터 전반 반등 신호, 신호가 노이즈일 가능성 등. 없으면 "없음(탐색함)"으로 명시, 비워두지 않는다.
- **확실성**: §13에 따라 확인됨/확인필요/반증있음 중 하나를 반드시 기입.
- 이 표는 **매도 지시가 아니라 원칙 대조 결과**다. 최종 판단은 §10에 따라 사용자 본인 몫.

**컬럼 설명**
- **시장/섹터**: `KR` 또는 `US` · 섹터 바구니 `A(반도체·AI)/B(바이오·헬스케어)/C(콘텐츠)/D(방산)/E(에너지·인프라)`
- **반대 논거(Bear/반증)** (§13 필수): 근거(bull)와 동일한 노력으로 찾은 반박 근거. "찾아봤지만 없음"과 "안 찾아봄"을 구분해서 기입 — 후자는 금지.
- **체크리스트 YES/7**: §3의 7문항 중 YES로 판단한 개수(추정치, 근거 불충분 시 낮게 잡을 것)
- **상태**: `관찰목록` → `매수후보`(체크리스트 통과) → `보유중` → `청산`
- **진입가/손절/추적손절**: §9 규칙 — 매수 전 반드시 세 값 모두 기입. 미확정이면 빈칸 유지(대충 채우지 않기)
- **확실성**: §13에 따라 확인됨/확인필요/반증있음 중 하나를 반드시 기입.
